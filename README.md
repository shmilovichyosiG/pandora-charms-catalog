# קטלוג חרוזי פנדורה

אתר סטטי, בלי שרת בכלל. לחיצה כפולה על `public/index.html` פותחת אותו בדפדפן.

## מבנה התיקיות

```
PandoraWebApp/
├── data.xlsx           ← Topic | SubTopic | Name | Image | Available | Note
├── Images/               ← תמונות jpg (charm_not_found.jpg = ברירת מחדל)
├── build.js                ← בונה מחדש את public/charms-data.js מתוך data.xlsx
├── build.bat                ← הפעלת build.js בלחיצה כפולה (Windows)
├── lib/xlsx-lite.js
└── public/
    ├── index.html             ← זה מה שפותחים בדפדפן
    ├── style.css
    ├── script.js
    ├── logo-placeholder.png     ← להחליף בלוגו האמיתי שלך (ר' למטה)
    └── charms-data.js            ← נוצר אוטומטית - אל תערוך ידנית
```

## הלוגו

בתוך `public/index.html` יש הערה שמסמנת בדיוק איפה, ותג `<img>` שמצביע כרגע
לקובץ `logo-placeholder.png`. כדי לשים את הלוגו שלך:

1. שים את קובץ התמונה שלך בתוך `public/` (למשל `logo.png`).
2. ב-`public/index.html`, שנה את `src="logo-placeholder.png"` ל-`src="logo.png"`.

**מידות מומלצות: 280×90 פיקסל** (רוחב × גובה), PNG עם רקע שקוף עדיף. אם התמונה
שלך ביחס שונה זה עדיין יעבוד יפה - `object-fit: contain` שומר על הפרופורציה
המקורית בלי לחתוך או למתוח, רק מגביל לגודל מקסימלי הזה.

## עמודת "זמינות" (עמודה E באקסל)

כתוב **בדיוק** את המילה `יש` או `אין` בעמודה הזו. זה מה שקובע אם התג על גבי
התמונה יהיה ירוק ("יש במלאי") או אדום ("אין במלאי"). כל ערך אחר (או תא ריק)
פשוט לא יציג תג בכלל.

## איך מוסיפים/מעדכנים חרוז

1. פתח את `data.xlsx` והוסף/ערוך שורה: נושא | תת-נושא | שם | שם קובץ תמונה (בלי `.jpg`) | יש/אין | הערה
2. שים את קובץ התמונה בתיקיית `Images`, עם השם שרשמת + `.jpg`.
3. שמור את `data.xlsx`.
4. **לחץ פעמיים על `build.bat`**.
5. רענן את `index.html` בדפדפן (Ctrl+Shift+R).

## דרישה טכנית יחידה

צריך **Node.js** מותקן, אבל **רק כדי להריץ את `build.bat`** — לא כדי להציג את האתר.
